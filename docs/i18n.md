# Internationalization (i18n)

## Overview

The template uses ASP.NET Core’s built-in localization:

- `IStringLocalizer<T>` for typed resources
- `.resx` files for translations
- `RequestLocalizationMiddleware` for culture detection
- Supports query string, cookie, and `Accept-Language` header

## Supported Cultures

Default cultures (configurable):

```csharp
var supportedCultures = new[] { "en", "en-AU", "en-US", "en-GB", "fr", "de", "es", "ja", "zh" };
```

## Adding a New Language

1. Create a new `.resx` file in `src/Company.Product.Web/Resources/`

   Example for German:
   ```
   src/Company.Product.Web/Resources/SharedResource.de.resx
   ```

2. Copy contents from `SharedResource.resx` and translate values.

3. Add the culture code to `supportedCultures` in `Program.cs` if not already present.

## Usage in Razor Pages

```cshtml
@inject IStringLocalizer<SharedResource> Localizer

<h1>@Localizer["Welcome"]</h1>
```

## Usage in Page Models

```csharp
public class IndexModel(IStringLocalizer<SharedResource> localizer) : PageModel
{
    public IStringLocalizer<SharedResource> Localizer { get; } = localizer;
}
```

## Culture Detection Order

1. Query string: `?culture=fr`
2. Cookie: `.AspNetCore.Culture=c=fr|uic=fr`
3. `Accept-Language` header

### Query String Example

```
https://localhost:5002/?culture=fr
```

### Cookie Example

Set via JavaScript or middleware:

```javascript
document.cookie = ".AspNetCore.Culture=c=fr|uic=fr; path=/";
```

## DataAnnotations Localization

Model validation messages are automatically localized when using `AddDataAnnotationsLocalization()` in `Program.cs`.

```csharp
[Required(ErrorMessage = "NameRequired")]
public string Name { get; set; }
```

Add to `SharedResource.resx`:
```xml
<data name="NameRequired" xml:space="preserve"><value>Name is required</value></data>
```

## Per-Page Resources (Optional)

If you prefer page-specific resources:

```csharp
public class IndexModel(IStringLocalizer<IndexModel> localizer) : PageModel
```

Create `Resources/Pages/IndexModel.fr.resx`.

## Testing Localization

- Use query string: `?culture=fr`
- Use browser language settings
- Use curl with header: `curl -H "Accept-Language: fr" https://localhost:5002`

## Best Practices

- Keep keys short and descriptive
- Use PascalCase keys matching code style
- Avoid embedding HTML in resources
- Provide fallbacks for missing translations
- Test with RTL languages if supporting them

## Tools

Consider tools like:

- Visual Studio Resource Editor
- ResX Manager
- Crowdin/Lokalise for collaborative translation

## Extending

For dynamic content or database-driven translations, implement a custom `IStringLocalizer` or use a library like `OrchardCore.Localization`.
